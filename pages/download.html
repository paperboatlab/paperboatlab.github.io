Then install the apps

  1. Pick an app

    paperboat app install julix

    Or from the Launcher's Apps page. Installing pulls the app's runtimes: they run in containers, so podman or docker is the only other thing the host needs.

  2. Open it

    paperboat app open julix ~/work

    Each app's page says what it does: Simplicial, Articula, Julix, Malachite.
